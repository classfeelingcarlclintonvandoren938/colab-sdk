# Artifact Format

> The `.tar.gz` archive produced by the Packager and executed by `runner.py` on the Colab VM.

---

## Produced By

`Packager.build(manifest)`

## Consumed By

`ColabSession.execute(name, runner_path)` — the artifact is extracted on the Colab VM, then `runner.py` is executed.

---

## Archive Structure

```
artifact.tar.gz
  └── <session_id>/<artifact_hash>/
      ├── runner.py                 # Entry point (generated by Packager)
      ├── metadata.json             # Execution metadata (generated by Packager)
      └── files/                    # All analyzed source files
          ├── app.py
          ├── training/
          │   └── trainer.py
          ├── utils/
          │   ├── model.py
          │   └── image.py
          └── config.py
```

### `<session_id>`

A unique identifier for the session (e.g., `lazy-gpu`). Prevents collisions when multiple sessions extract artifacts on the same VM.

### `<artifact_hash>`

Hex-encoded SHA256 digest of the entire `.tar.gz` content (before compression) bytesteam. Used for caching: if the VM already has a directory with this hash, extraction is skipped.

### `runner.py`

The generated entry point. Responsibilities:
1. Set up `sys.path` to include the `files/` directory
2. Import and call the target function with the provided arguments
3. Serialize the result using the stdout protocol
4. Handle exceptions and emit `__LAZY_ERROR__`

Generated structure:

```python
#!/usr/bin/env python3
"""Auto-generated runner for function: <function_name>"""

import json
import sys
import traceback
from pathlib import Path

# Add files directory to path
FILES_DIR = Path(__file__).parent / "files"
sys.path.insert(0, str(FILES_DIR))

def emit_result(value):
    print(f"__LAZY_RESULT__:{json.dumps({'status': 'ok', 'value': value})}", flush=True)

def emit_error(exc):
    tb = traceback.format_exc().splitlines(keepends=True)
    payload = json.dumps({
        "status": "error",
        "type": type(exc).__name__,
        "message": str(exc),
        "traceback": tb
    })
    print(f"__LAZY_ERROR__:{payload}", file=sys.stderr, flush=True)

# Import and execute the target function
# <import statement>  (generated by Packager)
from <module_path> import <function_name>

try:
    result = <function_name>(*<args>, **<kwargs>)
    emit_result(result)
except Exception as e:
    emit_error(e)
    sys.exit(1)
```

### `metadata.json`

```json
{
    "function_name": "train",
    "manifest_hash": "sha256:<hex>",
    "requirements_hash": "sha256:<hex>",
    "gpu": "T4",
    "args": [10],
    "kwargs": {"lr": 0.001},
    "created_at": "2026-07-26T12:00:00Z",
    "colab_version": "0.1.0"
}
```

### `files/`

Contains all source files from the `ExecutionManifest.files` list, preserving their relative paths. Each file is a verbatim copy of the original source file on the user's machine.

---

## Extraction on Colab VM

When the artifact is uploaded to the Colab VM:

1. The VM checks if `<session_id>/<artifact_hash>` already exists in the cache directory.
2. If cached: skip extraction.
3. If not cached: extract `.tar.gz`, create cache entry.

---

## Upload Path on Colab VM

```
/content/.colab-client/artifacts/<session_id>/<artifact_hash>/
```

Execution command:

```bash
cd /content/.colab-client/artifacts/<session_id>/<artifact_hash>
python runner.py
```

---

## Determinism Guarantee

The `artifact_hash` is computed from the deterministic byte stream of the `.tar.gz` file (before compression). This means:

- Same `ExecutionManifest` + same source file contents = same artifact hash
- Source file metadata (permissions, owner, timestamps) are **not** included in the archive
- File ordering in the archive is alphabetical by path

This guarantees that functionally identical manifests produce identical artifacts, enabling reliable caching.
